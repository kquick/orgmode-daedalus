* Overall rules

1. Metadata like ~#+TITLE~ and ~#+AUTHOR~ are concatenated (this is the same as
   if there were multiple metadata elements in the same file: i.e. inclusion has
   no effect).
2. Relative paths specified in ~#+INCLUDE:~ directives are relative to the file
   they are contained in.



1. Any OrgBody following an include is appended to the end of the last OrgBody in
   the included file.
2. Any include following another include in the same OrgBody will start at the
   same level (even though the orgbody was relocated).
3. Any first OrgBody block in an include is appended to the OrgBody where its include
   statement occurred.
4. Any include in the first block occurs at level 0.

5. minlevel is absolute for the file it includes, although the section nesting
   will return to the place it was when the include ends (although subsequent
   sections in the including file will be nested under the included file).
6. Rule #3 still holds even with a minlevel specification.
